Sentiment Analysis Dashboard

Python · NLP · Hugging Face · pandas · Streamlit 2026

Coming Soon

This project is currently in development. It will apply natural language processing to classify sentiment in text data — using a pre-trained transformer model from Hugging Face — and present the results in an interactive Streamlit dashboard with trend analysis and topic breakdown.

Planned Features

  • Data collection and preprocessing pipeline for text data
  • Sentiment classification using a fine-tuned Hugging Face transformer model
  • Topic modelling to identify recurring themes across positive and negative segments
  • Time-series sentiment trend charts and keyword frequency analysis
  • Interactive Streamlit dashboard with search, filtering, and export functionality
